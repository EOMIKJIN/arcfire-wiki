# 랜딩 플레이 영상

랜딩(`../index.html`)의 휴대폰 화면 안에서 재생되는 영상 자리다.

- 파일 이름: `gameplay.mp4` (이 폴더)
- 파일이 없으면 랜딩에 「플레이 영상 준비 중」이 표시된다(오류 아님).
- 권장 규격
  - 세로 화면 그대로(게임이 portrait). 1080×2340 또는 720×1560
  - H.264 MP4 · 30fps · 30~60초 · 20MB 이하 (GitHub 파일 100MB 제한 · 페이지 로딩 고려)
  - 개발 표시(FPS 숫자·테스트 문구·디버그 라벨)가 없는 release 빌드 화면
- 배포: `node tools/wiki/export-wiki-site.mjs` 가 이 폴더를 그대로 배포 폴더(`D:\arcfire-wiki`)로 복사한다.
