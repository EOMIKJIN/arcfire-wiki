Skills

You learn skills with skill points in the skill tree of the hub's Research Lab, then equip the ones you have learned into four skill slots. There are four branches — Combat, Navigation, Trade and Fleet — each split into tiers 1 to 7, for 57 skills in total (tiers 6–7 are "II" skills that power up an existing skill a second time). Higher tiers need higher levels and earlier skills, so the tree branches out as you go. The icons in the tables below are the same artwork used in the game.

Learn · equip · unequip (reworked 2026-10-20)

1. Learn

Skill points

You start with no skills and 0 skill points, and gain 1 point each time you level up. Tap an icon in the Research Lab skill tree to learn (unlock) it.

2. Equip

Four slots

Tap a learned skill's icon again to open the equip window. S1 · S2 = active · S3 · S4 = passive. A skill you have learned but not equipped has no effect.

3. Unequip

Unequip skill

Use [Unequip] under the slot in the loadout screen to free it, then equip another skill from the Research Lab. You cannot change skills during combat.

A II skill inherits its I skill Learning a II skill includes the full effect of the matching I skill plus the extra effect, so once you have the II you can no longer equip the I separately (one slot gives you I + II). II skills use their I skill's icon with a II mark.
What learning unlocks — Star Pathfinder Learning the tier-4 Navigation skill Star Pathfinder lets you pass all four frontier gateways leading out of the galaxy (learning it is enough; it does not need to be equipped). While a gateway is closed, the galaxy map says "Gateway Closed · Requires Star Pathfinder".
Not the same as the planet-development "Research Lab" facility The hub skill tree (this page) gives permanent traits to your pilot. The planet-development facility called "Research Lab" (levels 1–15) is a separate building that only changes R&D unlock timer speed and counter-terror detection. The shared name makes them easy to confuse.
