Skills

An SP-based talent tree learned at the hub's Research Lab, gated by pilot level and prerequisite skills. It has four branches — Combat, Navigation, Trade and Fleet — each split into tiers 1 to 7, for 57 skills in total (tiers 6–7 are "II" skills that power up an existing skill a second time). Higher tiers need higher levels and earlier skills, so the tree branches out as you go.

Not the same as the planet-development "Research Lab" facility The hub skill tree (this page) gives permanent traits to your pilot. The planet-development facility called "Research Lab" (levels 1–15) is a separate building that only changes R&D unlock timer speed and counter-terror detection. The shared name makes them easy to confuse.
Status (updated 2026-10-05) According to the in-game skill tree badges (skillRuntimeStatus.ts), 56 of 57 skills are "Complete" — learning them really changes combat, travel, trade and fleet numbers. Auto-combat skill cooldowns and durations are tuned by skill_auto_combat_policy.csv (1 turn = 8 seconds). Only the Wormhole Generator is "Partial" Partial — skipping one hop on warp works, while permanent portals are on hold.
