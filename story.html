스토리 · 미션

메인 스토리는 10개 장(챕터)으로 설계돼 있고, 현재 1장 「은폐된 진실」의 메인 퀘스트 30개가 모두 구현돼 있다(2026-10-15 기준). 직접 플레이할 이야기를 위해 메인 퀘스트는 장 제목과 짧은 도입 요약까지만 싣고, 퀘스트별 제목·줄거리·인물의 정체는 싣지 않는다.

인트로 — 게임을 시작하며

3페이지 컷신으로 크림슨의 침공, 스텔리움의 저항, 그리고 아크코어의 존재가 차례로 제시된다. 이어 캐릭터(직업) 선택 → 닉네임 입력 → 워프 연출 → 아르카디아 착륙 → 스텔라 아리스의 튜토리얼 안내로 이어진다.

1장 — 은폐된 진실

도입 요약 국경 행성에서 동기를 알 수 없는 살인사건이 일어나고, 플레이어는 그 수사에 휘말린다. 단서는 20년 전 함락된 변경 식민지 라이트홀드의 기록으로 이어진다 — 그날 무슨 일이 있었는지는 직접 확인하길 바란다.

1장은 메인 퀘스트 30개로 이어지며, 요구 레벨 Lv 1부터 Lv 44까지 단계적으로 열린다. 퀘스트 사이의 레벨 공백은 서브 의뢰와 수련으로 채운다.

2~10장

각 장은 최대 30개 메인 퀘스트 슬롯과 4개 분기 슬롯, 챕터 엔딩 컷신을 가질 수 있도록 뼈대가 짜여 있지만, 실제 시나리오는 아직 채워지지 않았다 — 제목조차 "챕터 2(시나리오 대기)" 같은 자리표시자 상태다. 이 위키는 존재하지 않는 내용을 지어내지 않는다.

서브 의뢰 목록 — 106개

메인 퀘스트를 뺀 의뢰 전체다 — 튜토리얼 임무 5개 · 행성 NPC가 주는 서브 의뢰 76개 · 바 게시판 의뢰 템플릿 25개. 스포일러를 피하려고 제목·지역·권장 레벨만 싣는다.

초반 행성 루트

온보딩~튜토리얼 트랙이 확정한 초반 이동 순서다.

아르카디아(본거지) → 베가 전초기지 → 솔라 항구 → 미네르바 딥(채굴·배달) → 드라코 성운 → 뉴에덴(오픈월드 진입점) → 오메가 스테이션(튜토리얼 트랙 종착)

미래 서사 구조 — 3개 아키타입

온보딩 3직업(렌 카제·미아 벨로·카일 드레이크, 플레이어 문서 참고)과는 별개로, 메인 스토리의 미착수 구간을 이어갈 구조로 화력지휘관 · 무역지배자 · 개척전략가 3개 서사 아키타입이 언급돼 있다 — 아직 구체적인 퀘스트로 구현되지는 않은 상위 설계 개념이다.
