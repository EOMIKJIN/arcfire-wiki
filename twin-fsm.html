AI 트윈 FSM

스텔라 트윈은 플레이어와 같은 버튼을 눌러 게임을 대신 플레이하는 테스트·학습용 AI다. 1~2초마다 상태 읽기 → 감독 점검 → 지금 화면에서 버튼 1개 결정 → 실행·기록을 반복한다. 이 문서는 표 값에서 자동 생성된다(2026-11-12 12:17 KST · 게임 저장소 c90ac3d1 2026-11-12).

붉은 줄 = 지금 열려 있는 문제·리스크(앞으로 해결할 부분). 녹색 원 숫자 = 우선순위 — 1지금 막혀 있거나 바로 고칠 것 · 2밸런스·관찰 · 3알고 수용. 아래 「열린 문제」 목록과 같은 항목이다.

열린 문제 · 리스크

  • 1서브 고르기가 출격 금지 길을 안 봄수정 중
    약한 함 출격 금지로 못 가는 서브를 제안으로 붙잡아, 갈 수 있는 다른 서브를 못 고름 → 같은 판정 함수로 거르기(김클로드 작업 중)
  • 1새 서브·정복 순위 판정 통일 — 빌드 대기빌드 대기
    16d 에서 감독이 갈 수 없는 서브를 매 분 「전환」(27회) · main 수정 완료(new_sub·conquest 도 같은 판정) · 다음 빌드(16f) 반영 전까지 남아 있음
  • 1정체 검사가 「패 → 수리」 경제 누수를 못 봄해야 함
    16c 수리 11회/시간·잔고 7.6만 → 0.9만은 정체 검사 5종 모두 OK 였음 → 잔고 급감·수리 횟수 검사 추가 필요
  • 1sandbox_022 「시리우스로 이동」 단계 미완료해야 함
    13c·14·15차 모두 obj_s022_b 완료 기록 0 — 단계 완료 판정 구멍 후보(원인 미조사)
  • 2L25 대 L22 3척 이동 조우 승률 ≈15%밸런스 기록
    목표 띠 35~60% 밖 — 수리비가 저레벨 수입을 넘어 경제 누수 · 트윈은 수리→패 미룸으로 막지만 원인은 조우 강도(밸런스 · 16차 기록)
  • 2「애매」 감지 문턱 미측정관찰 중
    차례 뒤집힘 6번/10분 문턱은 실기 교대 주기를 재지 않은 값 — 정상 교대가 더 빠르면 오발령 가능 · 16차 simple_order(ambiguous) 횟수로 표 조정
  • 2숙적 참전 · 동료 트윈 2·3 · 숙적 복제 — 미적용16차 뒤
    숙적 범용 참전(구현·검증 끝 · 16차 뒤 적용) · 동료 트윈·숙적 복제(설계) — 적용 뒤 숙적 빈도 최대 3배(대표님 「감안하고 간다」) · 보호 아닌 퀘스트 궤도전 패배 증가 가능
  • 3실전 세기 식의 근사관찰 중
    (선체+실드) × 강화 배수 × 피해 배수 — 기동(속도·선회 3~4%)·장착 칸 수 차이는 식 밖 · 칸 수가 다른 함끼리는 지금 탄 함 장착 기준 근사
  • 3사러 가기 헛걸음 1회는 남음수용
    진열가 ±14% 변동 — 첫 헛걸음 1회는 못 막고 2회째부터 기억이 막음

한 박자의 4층

1 · 상태 읽기

readSnapshot — 화면 · 위치 · 함선/격납고 · 잔고 · 퀘스트 단계 · 본편 제안 · 수련/정복/서브 후보 · 사러 가기 · 막힘 판정

2 · 감독(최소)

무진척 · 상위 순위 점검 · 핵심 정체 · 판단 부정확 → 단순 행동 1개 고정 · 기억 장치 갱신

3 · 버튼 결정

decideTwinAutopilotStep — 창 → 전투 버튼 → 화면별 우선순위(위에서 첫 번째)

4 · 실행·기록

결과 ok / no_effect / blocked · 같은 키 시도 상한 · 로그

허브 우선순위(위에서 첫 번째 1개)

  1. 허브 전투 중 → 대기
  2. 복구(포드·대파·함 없음) → 조선소
  3. 센 대파 함 회수 · 돌아온 주력함 · 출격 함 = 실전 세기 최대3⚑ 실전 세기 식의 근사 — (선체+실드) × 강화 배수 × 피해 배수 — 기동(속도·선회 3~4%)·장착 칸 수 차이는 식 밖 · 칸 수가 다른 함끼리는 지금 탄 함 장착 기준 근사
  4. 스킬 칸 교체 · 배울 스킬 → 연구소
  5. 사기·달기·팔기(조선소·무역소) · 재열기 대기 ≤60초3⚑ 사러 가기 헛걸음 1회는 남음 — 진열가 ±14% 변동 — 첫 헛걸음 1회는 못 막고 2회째부터 기억이 막음
  6. 강화(함선 저축 중이면 보조 몫 안에서만)
  7. 행성정보 · 퀘스트 통신 · 편입·중립화
  8. 핵심 루프 목표가 다른 곳 → 출발
  9. 대기 중 손상 수리 → 보조(바 의뢰·인스턴스) → 스캔 → 채굴 → 수색 → 탈출

어디로 갈지 — travelTarget

  1. 출격 전 학습(연구소 행성)
  2. 본편 제안 / 진행 퀘스트 목적지(레벨 숙제면 건너뜀)
  3. 사러 가기(헛걸음 행성 제외)
  4. G1: 새 서브 ↔ 정복1⚑ 서브 고르기가 출격 금지 길을 안 봄 — 약한 함 출격 금지로 못 가는 서브를 제안으로 붙잡아, 갈 수 있는 다른 서브를 못 고름 → 같은 판정 함수로 거르기(김클로드 작업 중)
  5. G2: 수련 ↔ 정복·합병
  6. 보조: 인스턴스 → 탈출
